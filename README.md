# Knight's Tour — ナイトツアー パズル

チェスのナイト（騎士）の動きだけを使って、盤面のすべてのマスをちょうど 1 回ずつ通る経路
「**ナイトツアー**」を自分で見つける、サイバーパンク調のパズルゲームです。

## 🔗 リンク

- リポジトリ: https://github.com/Sora3141/knight-tour-app
- デモ: https://sora3141.github.io/knight-tour-app/

## 概要

- ナイトの移動可能なマスをハイライト表示。クリック / タップで進みます。
- **盤面サイズを変更可能**（SIZE）。
- **UNDO**（1 手戻る）・**START / RESET**（やり直し）対応。
- 全マスを訪問できればクリア。

## 使用技術

- HTML / CSS / Vanilla JavaScript
- **Canvas 2D** による盤面描画

## 操作

| 操作 | 内容 |
|---|---|
| クリック / タップ | ハイライトされた移動先へナイトを進める |
| UNDO | 1 手戻す |
| START / RESET | 最初からやり直す |
| SIZE | 盤面の大きさを変更 |
